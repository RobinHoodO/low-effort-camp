# Task: Redesign Low Effort Camp app — Light, Minimal, Intuitive

## Context
This is a React + Vite + Tailwind + TypeScript + Wouter app for managing a burner camp (Low Effort Leftovers at Borderland 2026). It currently has a dark "campfire" theme and 6 pages. Data is seeded from Google Sheets.

## Goal
1. Complete visual overhaul: bright, light, minimalist, intuitive
2. Reduce to 3 tabs: Dashboard, Shifts, Points
3. Merge Campers/Layout/Kitchen into the Dashboard as collapsible sections
4. Dashboard should be the single source of truth — view AND edit everything inline
5. Integrate the new useSheetSync hook (already written at src/hooks/useSheetSync.ts)
6. The app should work without Google Sheets (falls back to seed data + localStorage)

## Design Tokens (Tailwind classes)
- Background: white, gray-50, gray-100
- Cards: bg-white, rounded-xl, shadow-sm, border border-gray-100
- Text: gray-900 (headings), gray-600 (body), gray-400 (muted)
- Accent: orange-500 (sparingly — buttons, active states, highlights)
- Success: green-500, Warning: amber-500, Danger: red-500
- Inputs: bg-white, border-gray-200, rounded-lg, focus:ring-orange-500
- Spacing: generous padding (p-4, p-6), gap-4, gap-6
- No dark mode. Remove all dark/zinc/slate/emerald color classes.
- Typography: font-sans, text-sm default, generous line-height
- Transitions: smooth, subtle

## Architecture Changes
1. In src/App.tsx: replace useCampData with useSheetSync. Wrap app in IdentityProvider (already exists). Only 3 routes: /, /shifts, /points.
2. Delete src/pages/Layout.tsx and src/pages/Kitchen.tsx (merge into Dashboard).
3. src/hooks/useCampData.ts should re-export from useSheetSync for backwards compat OR update all imports.
4. src/components/layout/AppShell.tsx: light redesign. Top bar white with subtle shadow. Sidebar white. Bottom nav white with border-t. Remove export/import buttons from top bar — put them in Dashboard footer.
